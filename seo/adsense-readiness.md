# AdSense readiness notes (2026-11-25)

Gray policy icon / “problem with your site's content” on a PDF **tool** site usually means **insufficient unique text** and/or **ads beside thin UI**, not a malware finding.

## Fixes shipped in this pass

1. **Ads after publisher content** on tool, home, tools index, pricing, compare, and guide pages.
2. **No ads** on guide/stub tools, contact, disclaimer, or mid-copy inside tool sections.
3. **Removed early ads** above home body copy and tools catalog.
4. **Hid guide/“coming soon” inventory** from the tools catalog listing.
5. **Added `/guides`** with four original articles (privacy, merge, e-sign, free vs paid).
6. **Rewrote `/pricing`** with real Free-forever copy + Product/Offer JSON-LD.
7. **Expanded home FAQs** (ads, construction, operator, guides, audience).

## After deploy — what you do in AdSense

1. Spot-check live: `/`, `/tools/merge-pdf`, `/guides/browser-pdf-privacy`, `/pricing`, `/about`.
2. Confirm ads appear **below** long text, not above an empty widget.
3. In AdSense → Sites → your domain → confirm code → **Request review**.
4. Expect days to a few weeks. Do not churn the site daily while under review.

## If rejected again

Add 2–3 more guide articles (compress for email, redaction basics, Word→PDF tips) and keep building organic traffic. Tool-only sites need ongoing editorial pages, not only widgets.
